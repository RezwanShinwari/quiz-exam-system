Quiz & Exam System

A simple Python program for creating and taking multiple-choice quizzes.

Features

- Add questions
- Add four options for each question
- Choose the correct answer
- View saved questions
- Take a quiz
- Check answers
- Calculate the final score
- Show the percentage
- Show PASS or FAIL
- Save quiz results

How to Run

Run the program with:

python main.py

Data

The program uses JSON files to store data:

questions.json
results.json
